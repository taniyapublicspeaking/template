Ready to explore?

Load a question bank or begin with the questions already available.

  1. Choose your questions: upload a CSV file or paste a published CSV URL in Question file or URL.
  2. Configure the quiz: filter by subject, grade, and topic, then set the start and end positions.
  3. Set your preferences: choose a learning mode, theme, timer, and voice options.
  4. Begin: press Start quiz. During the quiz, reveal answers, navigate between questions, or choose Present for a larger display.

Tip: use Reset settings to clear saved preferences and return to the default settings.

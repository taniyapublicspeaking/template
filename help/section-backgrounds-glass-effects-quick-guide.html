A copy-and-paste guide for section colours, page and section background images, contrast overlays, and readable glass panels—designed to fit a reusable CSS design system.

No external CSS, JavaScript, or image needed for this guide

Start with the right structure

Keep reusable design tokens in global.css. Use base classes for shared layout and modifier classes for appearance. The HTML chooses the classes; CSS defines how they look.

global.css

Variables, typography, section styles, background images, overlays and glass styles.

index.html

Section markup and class choices. Avoid repeating inline styles for every section.

1. Section background and text colours

Add only variables you don't already have in your :root.

:root {
    --bg-section: #ffffff;
    --bg-section-alt: #eff6ff;
    --bg-section-dark: #172554;

    --text: #172033;
    --text-muted: #64748b;
    --text-heading: #172554;
    --text-on-dark: #ffffff;
    --text-muted-on-dark: #cbd5e1;
}

Define a base section and reusable variants:

.section {
    padding-block: clamp(3rem, 7vw, 6rem);
    padding-inline: 1.25rem;
    background-color: var(--bg-section);
    color: var(--text);
    scroll-margin-top: 90px;
}

.section--white { background: var(--bg-section); color: var(--text); }
.section--light { background: var(--bg-section-alt); color: var(--text); }
.section--dark  { background: var(--bg-section-dark); color: var(--text-on-dark); }

.section--dark h2,
.section--dark h3 { color: var(--text-on-dark); }

.section--dark p { color: var(--text-muted-on-dark); }

2. Add a background image to the body

Use this when the image should sit behind the whole page. CSS image paths are relative to the stylesheet location.

body {
    margin: 0;
    font-family: var(--font-body);
    color: var(--text);
    background-color: var(--navy-dark);
    background-image: url("images/background.jpg");
    background-size: cover;
    background-position: center;
    background-repeat: no-repeat;
}

Path tip: If global.css and the images folder are both in the project root, use url("images/background.jpg"). If global.css is inside a css/ folder and images/ is next to it, use url("../images/background.jpg").

To apply an image to only one section, use a modifier class instead:

.section--image {
    background-image: url("images/section-background.jpg");
    background-size: cover;
    background-position: center;
    background-repeat: no-repeat;
}
<section class="section section--image" id="about">
    <div class="container">
        <h2>About Us</h2>
        <p>Content for this section.</p>
    </div>
</section>

3. Add a dark overlay for contrast

A photograph can be too bright or busy behind text. Place a gradient before the image in the background list; the first layer is drawn on top.

.section--image-overlay {
    background-image:
        linear-gradient(
            rgba(15, 23, 42, 0.45),
            rgba(15, 23, 42, 0.60)
        ),
        url("images/section-background.jpg");
    background-size: cover;
    background-position: center;
    background-repeat: no-repeat;
    color: #ffffff;
}

.section--image-overlay h2,
.section--image-overlay h3 { color: #ffffff; }

.section--image-overlay p { color: #f1f5f9; }

Increase overlay opacity for a darker image; reduce it to reveal more of the photo. Always check text contrast against the actual image.

4. Add a glass panel over the image

Glassmorphism uses a translucent surface, backdrop blur, a subtle border and a shadow. The blur is visible only when something is behind the panel.

Reusable glass CSS

.glass-panel {
    width: 100%;
    max-width: 800px;
    margin-inline: auto;
    padding: clamp(1.5rem, 5vw, 3.5rem);

    background: rgba(15, 23, 42, 0.62);
    -webkit-backdrop-filter: blur(18px);
    backdrop-filter: blur(18px);

    border: 1px solid rgba(255, 255, 255, 0.30);
    border-radius: var(--radius);
    box-shadow: 0 20px 50px rgba(0, 0, 0, 0.22);
    color: #ffffff;
}

.glass-panel h1,
.glass-panel h2,
.glass-panel h3 {
    color: #ffffff;
    font-family: var(--font-heading);
}

.glass-panel p {
    color: #f1f5f9;
    line-height: var(--text-leading, 1.75);
    max-width: var(--text-width-md, 60ch);
}

HTML example

<section class="section section--image-overlay" id="welcome">
    <div class="container">
        <div class="glass-panel">
            <span class="section-eyebrow">Welcome</span>
            <h2>Design with clarity</h2>
            <p>A translucent panel keeps content readable
               while allowing the background image to show through.</p>
        </div>
    </div>
</section>

Readability tip: Blur alone does not guarantee readable text. For a busy image, increase panel opacity (for example, from 0.48 to 0.65) or strengthen the overlay.

5. Troubleshooting checklist

  • Image missing: check the file exists and the URL is relative to global.css, not the HTML file.
  • Filename mismatch: check spelling, extension and letter case.
  • Image is covered: inspect main, wrappers and sections for opaque backgrounds.
  • Background unexpectedly disappears: a later rule like body { background: var(--off-white); } resets the background image too. Combine declarations or remove the conflicting shorthand.
  • Blur is not visible: ensure the panel is translucent and has an image or colour behind it.
  • Text is hard to read: increase the overlay or panel opacity and use high-contrast text. Test on mobile.
  • Fixed background behaves badly on mobile: omit background-attachment: fixed unless you have tested it on target devices.

6. Quick reference: class responsibilities

.section

Shared spacing, default colours and anchor offset.

.section--light / .section--dark

Section colour themes and readable text colours.

.section--image-overlay

Image background, crop behaviour and contrast overlay.

.glass-panel

Translucency, blur, border, radius, shadow and panel text.

Recommended approach: Keep design variables in global.css, choose section themes with modifier classes, and keep glass-panel styling separate from section layout. This makes the system reusable and easier to maintain.

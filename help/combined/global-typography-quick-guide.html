Global Typography CSS

A practical, nine-point quick guide to using the site's fonts, typography variables, text widths, and color tokens.

Use this page as a reference while building or updating pages. Examples assume your global CSS defines the variables and utility classes shown below.

1

Font Usage

Use Caveat for handwritten headings and decorative accents. Use Inter for paragraphs, buttons, and form controls.

Caveat — headings & accents Inter — readable body text 
<h1>Main Heading</h1>
<p>Regular paragraph text.</p>
<span class="accent-text">Made with care</span>
2

Font Variables

Change the font family once in :root to update the site consistently.

--font-heading: 'Caveat', cursive;
--font-body: 'Inter', 'Segoe UI', Arial, sans-serif;
  • --font-heading controls headings and accent text.
  • --font-body controls the default reading font.
3

Responsive Heading Sizes

The clamp() function lets headings scale with the viewport while respecting minimum and maximum sizes.

  • h1: clamp(3rem, 6vw, 5.6rem)
  • h2: clamp(2.25rem, 4vw, 3.7rem)
  • h3: 1.4rem

Pixel equivalents assume a 16px root font size.

4

Body Text Sizes

Apply utility classes to adjust text size without creating new CSS rules.

<p class="text-xs">Extra-small text</p>
<p class="text-sm">Small text</p>
<p class="text-base">Regular text</p>
<p class="text-lg">Large text</p>
  • .text-xs: 0.8rem
  • .text-sm: 0.9rem
  • .text-base: responsive 1rem–1.125rem
  • .text-lg: responsive 1.125rem–1.25rem
5

Text Block Widths

Use width utilities to keep text lines comfortable to read.

<div class="text-block-sm">Narrow content</div>
<div class="text-block">Standard content</div>
<div class="text-block-lg">Wide content</div>
  • .text-block-sm: 45ch
  • .text-block: 60ch
  • .text-block-lg: 70ch

These classes limit container width; they do not automatically center it.

6

Line Height

Line height controls the vertical space between lines of text.

--text-leading: 1.75;
--text-leading-tight: 1.5;
  • --text-leading: comfortable paragraph spacing.
  • --text-leading-tight: compact text, such as small.
7

Colors

Use your shared color variables instead of repeating hex values across component styles.

color: var(--text);
color: var(--muted);
background: var(--navy);
border-color: var(--border);
  • --text: primary text
  • --muted: secondary text
  • --navy: dark blue
  • --orange: accent
  • --white: white
8

Font Loading

Load Caveat and Inter in the HTML <head>. Fallback fonts are used if the web fonts cannot load.

<link rel="preconnect"
  href="https://fonts.googleapis.com">
<link rel="preconnect"
  href="https://fonts.gstatic.com" crossorigin>

<link href="https://fonts.googleapis.com/css2?family=Caveat:wght@400;500;600;700&family=Inter:wght@400;500;600;700;800&display=swap"
  rel="stylesheet">
9

Important Rules

  • Keep shared variables in :root.
  • Keep core typography in global.css.
  • Avoid duplicate font declarations in component styles.
  • Check component-specific CSS if a font looks incorrect.
  • Use Caveat sparingly for decorative text; use Inter for long paragraphs.

Recommended structure: Keep variables, resets, and typography in global.css, and use separate files for buttons, layout, and components.

How to Build Reusable Website Sections

A practical guide to building page sections that share a consistent structure while allowing different content, backgrounds, layouts, and spacing.

Core idea: create a repeatable section pattern, then customize it with modifier classes and content-specific components.

1. Start with a reusable section structure

Most content sections need a section wrapper, an inner container, an optional heading area, and a content area.

<section class="content-section" id="about">
  <div class="container">
    <header class="section-header">
      <p class="section-eyebrow">Who we are</p>
      <h2>About Us</h2>
      <p>A short introduction to this section.</p>
    </header>

    <div class="section-content">
      <!-- Add text, images, cards, lists, or other content -->
    </div>
  </div>
</section>

Use a unique id when the section should be reachable from navigation links. The .container keeps content aligned with the rest of your site.

Important: a section can contain any suitable content. The section pattern is reusable; the content inside it does not have to be the same on every page.

2. Why use a header inside a section?

The page-level <header> often contains the site logo and navigation. A separate <header class="section-header"> inside a section groups that section's own heading, subtitle, and introduction.

<section id="features">
  <div class="container">
    <header class="section-header">
      <h2>Our Features</h2>
      <p>What makes the service useful.</p>
    </header>

    <div class="section-content">
      ...
    </div>
  </div>
</section>

The section header is optional. If a section does not need a title or introduction, you can omit it. Using <header> inside a section does not replace or duplicate the main site header; it describes the section's own introductory content.

3. Define global section settings

Add section variables to the existing :root block in global.css. These values become defaults that your section components can reuse.

:root {
  --section-padding-block: 4.5rem;
  --section-padding-inline: 1.25rem;
  --section-content-width: 1160px;
  --section-heading-width: 700px;
  --section-gap: 2rem;
}
VariableControlsExample
--section-padding-blockSpace above and below a section.4.5rem

Reuse existing global tokens for colors, fonts, borders, radius, and shadows rather than defining unrelated values in every section.

4. Add a new section to your page

Copy the section structure, give it a unique ID, then replace the heading and content. A unique ID is helpful for navigation, skip links, and scroll-based active-section highlighting.

<section class="content-section" id="resources">
  <div class="container">
    <header class="section-header">
      <h2>Resources</h2>
      <p>Helpful links and downloads.</p>
    </header>

    <div class="section-content">
      <p>Place the section's content here.</p>
      <a href="/help">Visit the help center</a>
    </div>
  </div>
</section>

Make sure any navigation link to this section uses the matching fragment, for example <a href="#resources">Resources</a>.

5. Use modifier classes for section variations

Keep a shared base class and add an optional modifier when one section needs a different background, alignment, or spacing. This avoids building a completely separate component for every variation.

/* Shared base */
.content-section {
  padding: var(--section-padding-block)
           var(--section-padding-inline);
}

/* Optional variations */
.content-section--soft {
  background: var(--sky);
}

.content-section--dark {
  color: var(--white);
  background: var(--navy-dark);
}

.content-section--compact {
  padding-block: 2.5rem;
}

.content-section--wide .container {
  max-width: 1400px;
}

.content-section--centered {
  text-align: center;
}

Use the modifier in HTML like this:

<section class="content-section content-section--soft" id="about">
  ...
</section>

<section class="content-section content-section--compact" id="updates">
  ...
</section>

Class naming convention: content-section is the base component; content-section--soft is a modifier. The double hyphen is a naming convention, not special CSS syntax.

6. Choose a content layout

The section wrapper controls spacing and background. A child layout class controls how the content inside is arranged.

Two-column layout example

<section class="content-section" id="about">
  <div class="container">
    <div class="content-layout content-layout--two-column">
      <div>
        <h2>Our Story</h2>
        <p>Text content goes here.</p>
      </div>

      <div>
        <img src="images/team.jpg" alt="Our team">
      </div>
    </div>
  </div>
</section>
.content-layout--two-column {
  display: grid;
  grid-template-columns: repeat(2, minmax(0, 1fr));
  gap: 2rem;
  align-items: center;
}

.content-layout img {
  display: block;
  width: 100%;
  height: auto;
  border-radius: var(--radius);
}

@media (max-width: 700px) {
  .content-layout--two-column {
    grid-template-columns: 1fr;
  }
}

Other useful inner layouts include a text column, media-and-text layout, list, feature grid, quote, or call-to-action. Use the layout that fits the content rather than forcing every section into the same arrangement.

7. Put reusable cards inside a section

Sections and cards are separate reusable layers: the section sets the overall space and context, while the card grid arranges individual items.

<section class="content-section content-section--soft" id="features">
  <div class="container">
    <header class="section-header">
      <h2>Our Features</h2>
      <p>Explore the key features.</p>
    </header>

    <div class="card-grid">
      <article class="single-card">
        <h3>Feature One</h3>
        <p>A short description.</p>
      </article>

      <article class="single-card">
        <h3>Feature Two</h3>
        <p>A short description.</p>
      </article>
    </div>
  </div>
</section>

For more details on card counts, column settings, icon/image modifiers, and card layouts, use your separate Card Sections — Quick Usage Guide.

8. Make sections responsive

Use a flexible content width, reasonable side padding, and media queries for layouts that need to change on smaller screens.

.content-section {
  padding: var(--section-padding-block)
           var(--section-padding-inline);
}

.container {
  width: 100%;
  max-width: var(--section-content-width);
  margin-inline: auto;
}

@media (max-width: 700px) {
  .content-section {
    padding-block: 3rem;
    padding-inline: 1rem;
  }

  .section-header {
    margin-bottom: 1.5rem;
  }
}

Preview your page at desktop, tablet, and mobile widths. Check for long headings, wide images, buttons that wrap, and layouts that become too cramped.

9. Accessibility and semantic HTML

  • Use <section> for a distinct thematic area of the page. Give it a heading where appropriate.
  • Use heading levels in a meaningful order: usually one page-level h1, followed by section h2 headings and nested h3 headings.
  • Give important sections unique IDs if they are linked from the navigation.
  • Use descriptive link text such as “Read the documentation” rather than “Click here”.
  • Add useful alt text to meaningful images; use alt="" for decorative images.
  • Keep text contrast strong, and make sure keyboard focus is visible.

11. Quick checklist

  • Use a reusable <section> wrapper and an inner .container.
  • Add a section heading and introduction when they help explain the content.
  • Set global spacing and width values in the existing :root block.
  • Use a base section class plus optional modifiers for backgrounds and spacing.
  • Keep inner layout classes separate from the outer section styles.
  • Use a unique ID when a section needs a navigation link.
  • Test all sections at desktop, tablet, and mobile widths.
  • Use semantic headings, accessible link text, and suitable image alt text.

Keep responsibilities separate: the section controls the surrounding layout and spacing; inner components such as cards, images, forms, and buttons control their own content presentation.

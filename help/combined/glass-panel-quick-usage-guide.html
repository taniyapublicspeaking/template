Glass Panel — Quick Usage Guide

Use one reusable glass-panel base class with small, predictable modifiers for tint, blur, spacing, corners, shadows, and interaction.

At a glance

The base class provides the shared glass surface. Add modifier classes only when a panel needs a variation. The component uses the same navy, blue, orange, typography, radius, and shadow tokens as the rest of the site.

Core rule: start with .glass-panel, then add modifiers such as .glass-panel--blue or .glass-panel--compact. Use __ classes for content inside the panel.

2. Base class

The base class defines padding, translucency, backdrop blur, border, corner radius, shadow, text color, and transitions. Keep shared styles here rather than repeating them for every variation.

.glass-panel {
  position: relative;
  min-width: 0;
  padding: 1.5rem;
  background: rgba(255, 255, 255, 0.65);
  -webkit-backdrop-filter: blur(16px);
  backdrop-filter: blur(16px);
  border: 1px solid rgba(255, 255, 255, 0.55);
  border-radius: var(--radius-small, 14px);
  box-shadow: var(--shadow, 0 20px 50px rgba(15, 23, 42, 0.08));
  color: var(--text, #172033);
  transition: background-color 0.25s ease,
              border-color 0.25s ease,
              box-shadow 0.25s ease,
              transform 0.25s ease;
}

Fallback values in var() keep the component working if a global token is missing.

4. Content helper classes

Use these optional classes to keep headings, body text, and icons consistent inside the panel.

ClassPurpose
.glass-panel__titleHeading using Caveat and a tight line-height.
.glass-panel__textBody copy with consistent line-height.
.glass-panel__iconSquare icon container for a symbol or inline icon.
<div class="glass-panel">
  <span class="glass-panel__icon" aria-hidden="true">✦</span>
  <h3 class="glass-panel__title">Panel title</h3>
  <p class="glass-panel__text">A short description goes here.</p>
</div>

Clickable panel

When the whole panel navigates somewhere, use an anchor instead of a generic div.

<a href="/services.html"
   class="glass-panel glass-panel--light glass-panel--interactive"
   style="display:block;color:inherit;text-decoration:none;">
  <h3 class="glass-panel__title">Explore services</h3>
  <p class="glass-panel__text">Read about what we offer.</p>
</a>

Accessibility: keep visible keyboard focus, ensure text contrast, and use --interactive only when the element performs an action. Do not show a pointer cursor on non-clickable content.

6. Combining modifiers

Multiple modifiers can be applied to the same element. CSS rule order and specificity determine which rule wins, not the order of classes in the HTML.

<div class="glass-panel glass-panel--blue glass-panel--blur-lg
            glass-panel--rounded glass-panel--shadow-soft">
  <h3 class="glass-panel__title">Featured content</h3>
  <p class="glass-panel__text">Blue tint, strong blur, rounded corners, soft shadow.</p>
</div>

Use one tint modifier at a time, then combine it with a blur, spacing, shape, or shadow modifier where useful.

7. Where to put the CSS

  1. Keep design tokens in :root in global.css.
  2. Add the shared .glass-panel rules and modifiers to the component section of global.css.
  3. Reuse the same class names across the site instead of copying styles into every page.
  4. Keep page-specific layout rules, such as a panel grid or hero positioning, in the relevant section stylesheet.
/* Example page layout — separate from the component */
.feature-panel-grid {
  display: grid;
  grid-template-columns: repeat(3, minmax(0, 1fr));
  gap: 1.25rem;
}
@media (max-width: 760px) {
  .feature-panel-grid { grid-template-columns: 1fr; }
}

8. Troubleshooting

ProblemLikely causeSolution
Blur is not visibleBackdrop is a flat color or browser support is limited.Place panel over an image or gradient; retain the translucent background fallback.
Text is hard to readInsufficient contrast between text and surface.Adjust opacity or choose a more suitable tint and text color.
Panel feels bulkyBase padding and spacious modifier are both generous.Use --compact or adjust the base padding.
Hover effect distractsMovement or shadow is too strong.Reduce hover transform/shadow or remove --interactive.
Rendering feels slowLarge blurred surfaces or many overlapping layers.Use moderate blur and avoid stacking many backdrop-filter layers.

Performance note: large blurred areas can be expensive to render, especially on mobile. Prefer moderate blur and avoid many overlapping glass layers.

9. Quick checklist

  • Start with .glass-panel.
  • Choose one tint modifier if the default surface is not suitable.
  • Adjust blur, spacing, radius, or shadow only when needed.
  • Use __title, __text, and __icon for consistent inner content.
  • Place panels over a background that makes the glass effect visible.
  • Check text contrast, keyboard focus, reduced motion, and mobile performance.
  • Keep the reusable component in global.css and page layout separate.
